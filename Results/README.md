# Results

Tables and figures for the LCDM / Model 1 / Model 2 MCMC runs.

Chain and log-probability paths are defined in `paths.py`. To regenerate everything:

```bash
python Results/run_all.py
```

Individual steps: `run_aic_bic.py`, `run_getdist_triangles.py`, `run_whisker.py`, `run_fs8_residuals.py`.
